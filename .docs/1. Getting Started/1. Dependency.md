## Dependencies

tvoid lib depends on Architectury and Fabric API.

Adding tvoid lib as a dependency to your mod should be enough, as it will
automatically check for its requirements, but you can still specify your
own versions for those mods, especially if you require specific functionality.

## Add Dependencies to your mod

### Common
#### build.gradle
    dependencies {
        localRuntime "maven.modrinth:tvoidlib:$rootProject.tvoidlib_version"
        implementation "net.tvoid.lib:tvoidlib:0.0.1-SNAPSHOT"
    }


### Fabric
#### fabric.mod.json
    "depends": {
    "tvoidlib": ">=0.0.1-BETA"
    }


### Neoforge
#### neoforge.mods.toml
    [dependencies.yourmod]]
    modId = "tvoidlib"
    type = "required"
    versionRange = "[0.0.1-EXAMPLE, 0.0.4-BETA)"
    ordering = "AFTER"
    side = "BOTH"
