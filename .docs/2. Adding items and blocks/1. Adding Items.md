## Item Registrars

In your mod, declare a new item registrar like so:

    private static final ItemRegistrar REG = new ItemRegistrar(yourmod.modId);

REG can be any name makes sense to you.

## Declaring items

You can now declare items in a couple different ways:

    public static final RegistrySupplier<Item> RUBY = REG.item("ruby");

This will create a simple item with basic default properties, this is suitable for any "Ingredient type item" that doesn't require any special functionality.

Alternatively:

    // Custom stack limited item.
    public static final RegistrySupplier<Item> RUBY_PEARL = REG.item("ruby_pearl", p -> new Item(p.stacksTo(16)));

    // Multiple properties food item.
    public static final RegistrySupplier<Item> RUBY_STEAK = REG.item("ruby_steak", p -> new Item(p.stacksTo(16).food(Foods.RUBY_STEAK)));

    // Simple armor item.
    public static final RegistrySupplier<Item> RUBY_HELMET = REG.item("ruby_helmet", p -> new Item(p.humanoidArmor(YourArmorMaterials.RUBY, ArmorType.HELMET)));

    // Custom subcategory item.
    public static final RegistrySupplier<Item>  = REG.item("", p -> new WeirdItem(p.stacksTo(16)));

## Registering the Items

After adding your items, you can create a simple method like so:

    public static void reg() {
        REG.Items();
    }

And make sure to call this method from your mod's entrypoint, like so:

    public static void init() {
        YourItems.reg();
        YourBlocks.reg();
        ...
    }
